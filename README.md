# EduAI – AI Powered Personalized Learning & Skill Assessment Platform

## 📌 Problem Statement

Traditional education systems follow a **one-size-fits-all learning approach**, where all students receive the same learning materials regardless of their knowledge level or learning speed.
As a result, many students struggle to identify their **skill gaps** and do not receive personalized guidance to improve their learning.

There is a need for a **smart educational platform** that can analyze student performance and recommend personalized learning paths.

---

## 💡 Solution

**EduAI** is an **AI-powered personalized learning platform** that helps students identify their strengths and weaknesses through skill assessments and generates a customized learning path to improve their knowledge.

The system analyzes quiz performance, detects skill gaps, and recommends the most effective learning resources and topics for improvement.

---

## 🚀 Key Features

### 1️⃣ User Authentication

* Student signup and login
* Simple and clean educational interface

### 2️⃣ Skill Assessment Test

* Students take quizzes to evaluate their knowledge
* System calculates skill score based on answers

### 3️⃣ AI Skill Gap Analysis

* Detects:

  * Strong topics
  * Average topics
  * Weak topics
* Generates a **Skill Gap Report**

### 4️⃣ Personalized Learning Path

* AI recommends a learning roadmap
* Topics arranged from **basic → advanced**

### 5️⃣ Student Dashboard

Displays:

* Skill score
* Learning progress
* Weak areas
* Recommended topics
* Performance charts

### 6️⃣ Progress Tracking

* Tracks completed quizzes and lessons
* Updates recommendations dynamically

## 📊 How It Works

1. Student signs up on the platform
2. Student takes a **skill assessment quiz**
3. AI analyzes the answers and detects skill gaps
4. System generates a **personalized learning path**
5. Student dashboard shows **progress and improvement**
